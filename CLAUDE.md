# CLAUDE.md — Next.js + SQLite SaaS Template

> This document defines the development standards, conventions, and patterns for this Next.js 15 + SQLite SaaS project. It is intended for use by Claude Code and all developers working on this codebase.

## Stack & Versions

- **Next.js**: 15 (App Router)
- **Database**: SQLite (via `better-sqlite3` or Turso)
- **ORM**: Drizzle ORM
- **Styling**: Tailwind CSS
- **Authentication**: NextAuth.js
- **Deployment**: Vercel
- **Package Manager**: pnpm
