# CLAUDE.md - Next.js + SQLite SaaS Project Template

## Stack & Versions

- **Framework**: Next.js 15 App Router

- **ORM**: Drizzle ORM
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
- **TypeScript**: 5.x
- **Node.js**: 18.x LTS or higher
