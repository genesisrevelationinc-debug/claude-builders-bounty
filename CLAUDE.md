# Project Guide for Next.js + SQLite SaaS

## Stack & Versions

- **Next.js**: v15.0.0 (App Router)
- **SQLite**: better-sqlite3 or Turso (LibSQL)
- **ORM**: DrizzleORM (primary choice), Prisma (fallback)
- **Styling**: TailwindCSS
- **Type Safety**: TypeScript strict mode enabled
- **Deployment**: Vercel
