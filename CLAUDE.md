# CLAUDE.md — Coding Guidelines for Next.js + SQLite SaaS

This document defines the coding standards and conventions for this Next.js 15 + SQLite SaaS project. Follow these rules strictly to maintain consistency and quality.

## Stack & Versions

- **Next.js**: 15 (App Router)
- **Database**: SQLite via [Turso](https://turso.tech/) (libSQL)
- **ORM**: Drizzle ORM
- **Styling**: Tailwind CSS
- **Authentication**: NextAuth.js
- **Deployment**: Vercel
