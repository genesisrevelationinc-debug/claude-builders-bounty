# CLAUDE.md - Development Guide for Next.js + SQLite SaaS

This document provides opinionated guidelines for working on this Next.js + SQLite SaaS project. These conventions are designed to maintain consistency, improve code quality, and reduce cognitive overhead during development.

## Stack & Versions

- **Next.js**: 15 (App Router)
- **Database**: SQLite (better-sqlite3 or Turso)
- **Styling**: Tailwind CSS
- **ORM**: Drizzle ORM
- **Authentication**: NextAuth.js
- **Deployment**: Vercel
- **Package Manager**: pnpm
