# Project Style Guide: Next.js + SQLite SaaS

> This document defines our team's conventions for a Next.js 15 + SQLite SaaS project.
> It provides context for developers and AI assistants like Claude Code.

## Stack & Versions

- **Next.js**: 15.3+ (App Router)
- **Database**: SQLite (better-sqlite3 or Turso)
- **Data**: Drizzle ORM (Postgres or SQLite adapter)
- **Migrations**: Drizzle Kit
- **Styling**: Tailwind CSS
- **Testing**: Playwright (E2E), Jest (unit)
