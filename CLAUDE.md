# CLAUDE.md — Next.js + SQLite SaaS Project

> **Opinionated development guide for Claude Code**  
> Stack: Next.js 15 App Router + SQLite (better-sqlite3 or Turso)

---

## Stack & Versions

- **Next.js**: `15.x` (App Router)
- **Runtime**: Node.js 20+
- **Database**: SQLite via `better-sqlite3` or `@libsql/client`
- **ORM**: None — raw SQL for full control
- **Styling**: Tailwind CSS
- **Deployment**: Vercel (preferred) or fly.io
